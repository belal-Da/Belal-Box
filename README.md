# Belal Box

1. GitHub-এ নতুন repo বানিয়ে এই ফোল্ডারের সব ফাইল (`.github` সহ) আপলোড করুন (branch: main)।
2. Actions ট্যাব → **Build APK** → অপেক্ষা করুন → নিচে **BelalBox-apk** আর্টিফ্যাক্ট ডাউনলোড করুন।
3. অ্যাপ খুলে ⚙️ সেটিংসে API Key / Base URL দিন → **Fetch Models** → মডেল বেছে নিন।

ওয়েব ভার্সনের জন্য `www/` ফোল্ডারটা Vercel-এ দিলেই চলবে।
